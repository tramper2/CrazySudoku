# Crazy Sudoku 게임 기획서 (Game Design)

본 문서는 GitHub Pages에 배포할 **Crazy Sudoku** 웹 애플리케이션의 핵심 게임 규칙, 디자인 테마, UI/UX 구조를 설명합니다.

---

## 1. 게임 규칙 (Rules)

### 1.1. 기본 스도쿠 규칙
- 9x9 격자판에 1부터 9까지의 숫자를 채워 넣습니다.
- 각 행(Row), 각 열(Column), 그리고 3x3 크기의 작은 사각형(Box)에 1부터 9까지의 숫자가 중복 없이 하나씩만 들어가야 합니다.

### 1.2. 난이도 구분
- **Easy**: 45개의 숫자가 공개된 상태로 시작합니다.
- **Medium**: 35개의 숫자가 공개된 상태로 시작합니다.
- **Hard**: 25개의 숫자가 공개된 상태로 시작합니다.
- **Crazy (크레이지 모드)**: 
  - 기본적으로 **Hard** 레벨의 공개 숫자로 시작합니다.
  - 추가 디버프와 아이템 시스템이 활성화됩니다.

---

## 2. 크레이지 모드 전용 특수 효과 (Crazy Features)

### 2.1. 디버프 (Debuffs)
크레이지 모드에서는 플레이어에게 제약 사항을 주는 디버프가 무작위 시간 간격(예: 30초~45초 사이)으로 발동합니다.
1. **눈부심 테마 (Flash Bang)**: 화면이 3초간 새하얗게 변한 뒤 서서히 네온 다크 모드로 복귀하여 플레이어의 흐름을 끊습니다.
2. **숫자 숨바꼭질 (Number Hide)**: 5초 동안 그리드 상의 모든 입력된 숫자들의 색상이 배경색과 똑같아져(보이지 않게 됨) 플레이어의 기억력을 시험합니다.
3. **지진 (Earthquake)**: 보드가 좌우로 1초간 심하게 흔들립니다.

### 2.2. 아이템 시스템 (Items)
플레이어는 크레이지 모드 시작 시 3개의 아이템 포인트를 가지며, 게임 중에 다음과 같은 아이템을 사용하여 위기를 돌파할 수 있습니다.
1. **돋보기 (Reveal Hint)**: 선택한 셀의 정답 숫자를 채워줍니다. (비용: 1포인트)
2. **방패 (Shield)**: 1회의 오답 감점(Life 차감)을 무효화합니다. (비용: 1포인트)
3. **진정제 (Purify)**: 현재 걸려 있는 디버프를 즉시 해제하고 15초 동안 디버프 면역 상태가 됩니다. (비용: 1포인트)

## 3. UI 및 디자인 테마

- **메인 컬러**: 네온 바이올렛 (#8b5cf6), 일렉트릭 사이언 (#06b6d4), 딥 스페이스 블랙 (#0b0f19)
- **Glassmorphism**: 보드판과 모달 팝업은 미려한 반투명 백그라운드에 블러 필터(`backdrop-filter: blur(12px)`)를 주어 미래지향적인 느낌을 구현합니다.
- **마이크로 애니메이션**:
  - 숫자를 선택했을 때 동일한 숫자가 들어 있는 모든 셀에 맥박이 뛰는 듯한(pulsing) 효과를 줍니다.
  - 숫자가 성공적으로 들어갈 때, 오답일 때 각각의 흔들림(shake) 또는 반짝임(glowing) 피드백이 제공됩니다.

---

## 4. 실시간 명예의 전당 (Leaderboard)

LootLocker BaaS 서비스를 활용하여 웹 서버 없이도 작동하는 실시간 랭킹 시스템을 운영합니다.
- **등록 조건**: 게임을 완료(성공)한 경우에만 닉네임 기입 폼이 활성화됩니다.
- **점수 규칙**: 오름차순(Ascending) 정렬로 설정되어, 클리어 소요 시간(초 단위)이 가장 짧은 유저가 1위를 차지하게 됩니다.
- **갱신 보호**: 플레이어 식별 세션을 유지하여, 본인의 이전 최고 기록보다 현재 클리어 기록이 **단축되었을 때만** 서버의 점수가 업데이트됩니다. (중복 등록 도배 방지)

---

## 5. 로컬 스토리지 데이터 저장 구조

브라우저 종료 후에도 이어할 수 있도록 다음 상태를 실시간 저장합니다.
- `crazy_sudoku_game_state`: 현재 보드 배열(원본 퍼즐, 유저 입력, 마스킹 정보, 메모 내역)
- `crazy_sudoku_stats`: 최단 클리어 타임, 최고 난이도 클리어 횟수, 크레이지 모드 클리어 횟수 등
- `sudoku_player_id`: LootLocker 연동에 사용되는 게스트 고유 식별 키
- `sudoku_nickname`: 유저가 마지막으로 명예의 전당 등록 시 사용한 닉네임 (자동완성용)
