# 🌌 Crazy Sudoku

> **네온 비주얼과 스릴 넘치는 디버프, 전략적 아이템이 가득한 차세대 웹 스도쿠 게임!**

Crazy Sudoku는 기존의 조용한 스도쿠 게임에서 탈피하여 화려한 네온 스타일 그래픽, 글래스모피즘(Glassmorphism) UI와 함께 실시간 방해 요소(디버프)를 극복하며 퍼즐을 푸는 새로운 감각의 웹 게임입니다.

---

## 🌟 주요 특징 (Key Features)

1. **난이도별 스도쿠 생성 & 백트래킹 코어**
   - 쉬움(Easy), 보통(Medium), 어려움(Hard), 그리고 크레이지(Crazy) 난이도를 제공합니다.
   - 수학적 백트래킹 알고리즘을 사용하며, 유일한 해(Unique Solution)만을 가집니다.

2. **🔥 크레이지 모드 (Crazy Mode)**
   - 플레이 도중 주기적으로 플레이어를 방해하는 디버프가 발생합니다:
     - ⚡ **플래시 뱅 (Flash Bang)**: 화면이 일시적으로 밝아졌다가 돌아오며 시야를 방해합니다.
     - 🌋 **지진 (Earthquake)**: 보드 전체가 흔들려 몰입을 방해합니다.
     - 👁️ **숫자 숨바꼭질 (Number Hide)**: 기입된 숫자들의 색상이 배경과 같아져 잠시 보이지 않게 됩니다.

3. **🛠️ 특수 방어 아이템**
   - 크레이지 모드 전용 포인트(3점)를 활용해 위기를 탈파할 수 있습니다:
     - 🔍 **돋보기 (Reveal)**: 선택한 칸의 정답 숫자를 힌트로 바로 채워 넣습니다.
     - 🛡️ **방패 (Shield)**: 오답 시 생명력(하트)이 깎이는 것을 1회 방어해 줍니다.
     - 🪄 **정화 (Purify)**: 현재 활성화된 디버프를 해제하고 15초 동안 모든 디버프 면역 버프를 얻습니다.

4. **✏️ 스마트 후보수 메모 (Auto-Candidates & Auto-Pruning)**
   - **자동 후보수**: 단 한 번의 클릭으로 비어있는 모든 칸에 들어갈 수 있는 유효 숫자 목록을 자동으로 채워 줍니다.
   - **후보수 자동 제거**: 숫자가 입력되거나 힌트 아이템이 사용되면, 해당 라인(행/열) 및 3x3 박스 내에서 배치 불가능해진 후보수가 자동으로 소거되어 효율적인 추론을 돕습니다.

5. **💾 로컬 자동 저장**
   - 창을 닫거나 새로고침하더라도 이전 플레이 상태(타이머, 라이프, 남은 포인트, 메모 및 그리드)를 안전하게 이어 나갈 수 있습니다.

## 🚀 시작하기 & 배포 방법 (How to Run & Deploy)

### 로컬에서 실행하기
이 프로젝트는 서버 사이드 언어(Node.js, PHP 등) 없이 순수하게 브라우저만으로 동작하는 정적(Static) 웹사이트입니다.
- `Source/index.html` 파일을 크롬 등 웹 브라우저에서 직접 더블 클릭하여 실행하거나, VS Code의 `Live Server` 확장을 사용해 실행할 수 있습니다.

### GitHub Pages (gh-pages) 배포 방법
1. 본 프로젝트의 전체 파일들을 GitHub 원격 저장소에 올립니다.
2. 레포지토리의 **Settings -> Pages** 탭으로 이동합니다.
3. **Build and deployment** 항목에서 브랜치를 `main`으로 설정하고 경로를 루트(`/`)로 지정한 뒤 **Save**를 누릅니다.
4. 수 분 내에 GitHub에서 제공하는 무료 호스팅 도메인으로 게임 배포가 완료됩니다.
